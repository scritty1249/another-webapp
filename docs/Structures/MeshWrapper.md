# MeshWrapper

A common structure used to encapsulate an object that has a model consisting of one or more [`Geometries`](<../Objects/ThreeJS References.md#buffergeometry>) or [`Materials`](<../Objects/ThreeJS References.md#material>), that cannot be represented as a single [`Object3D`](<../Objects/ThreeJS References.md#object3d>).

> **Extends** : [`three.Group`](<../Objects/ThreeJS References.md#group>)

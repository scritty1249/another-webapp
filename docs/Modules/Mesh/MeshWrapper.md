# MeshWrapper

A common structure used to encapsulate an object that has a model consisting of one or more [`Geometries`](<../../ThreeJS References.md#buffergeometry>) or [`Materials`](<../../ThreeJS References.md#material>), that cannot be represented as a single [`Object3D`](<../../ThreeJS References.md#object3d>).

> **Extends** : [`three.Group`](<../../ThreeJS References.md#group>)
